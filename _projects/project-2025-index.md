Project 2025 was a controversial plan developed by the Heritage Foundation think-tank that outlined a policy framework for a future conservative US president. The 900-page publication lacked an index, so I created one to provide researchers with another approach to navigating the contents of the document.

The index was developed as a FastHTML app with a vector database to allow users to go beyond keyword search. Each indexed item contained LLM-generated summaries accessible via tooltip situating each item within the document.
